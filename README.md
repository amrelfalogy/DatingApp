# Dating App

A **Full-Stack Dating Application** built with **ASP.NET Core Web API** and **Angular 20**.

This project is currently **Work in Progress** and is being developed as a practical full-stack project while exploring and applying modern Angular development patterns and the latest Angular features.

## 🚀 Modern Angular

The frontend is built with **Angular 20**, with a focus on modern Angular development practices, including:

* **Standalone Components**
* **Signals** for reactive state and modern data flow
* **`inject()` Function** for dependency injection
* **Modern Control Flow** with `@if` and `@for`
* **Zoneless Change Detection**
* Modern Angular architecture and application patterns

The Angular side of the project is continuously evolving as new features are implemented and explored.

## 🛠️ Tech Stack

### Frontend

* Angular 20
* TypeScript
* HTML5 / CSS / SCSS
* Tailwind
* RxJS

### Backend

* ASP.NET Core Web API
* Entity Framework Core
* .NET 10
* SQLite
* RESTful APIs
* Authentication & Authorization
* Entity Framework Core Migrations

## 🎯 Project Goals

The main goals of this project are to:

* Build a real-world **Full-Stack application** using Angular and .NET.
* Practice modern **Angular 20** features and patterns.
* Improve understanding of frontend-to-backend **data flow and API integration**.
* Apply clean and maintainable application architecture.
* Gain practical experience with authentication, database operations, and backend API development.
* Continuously improve the project as I learn and adopt newer Angular and .NET practices.
